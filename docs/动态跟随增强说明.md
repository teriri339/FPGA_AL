# 动态跟随增强说明

本次基于已上板确认可运行的 `9a07320` 版本，只调整模板跟踪模块。参考案例中的位置和速度预测思路，独立实现适配现有模板匹配的定点预测；没有直接复制参考项目的 RTL。

- 匹配成功时，显示的位置仍采用实际匹配结果；预测位置只用于下一帧的搜索中心。
- 速度按每轴每帧最多 8 像素限制，加速、停止和反向时及时更新，同方向减速时进行平滑。预测中心限制在有效范围内。
- 速度仅在跟踪状态和匹配置信度满足门限时更新；复位、重新选取、丢失和处理超时等情况会清零速度。默认置信度门限与原有匹配判定一致，也可单独配置。
- 这是自适应位置—速度预测，并非完整的协方差卡尔曼滤波。原有模板、匹配和重捕获机制继续使用。

仿真覆盖速度运算、停止和反向、置信度门限、画面边界、目标丢失和重捕获，以及 720p 时序下的快速重捕获。四组合成运动场景中，增强版本 24 帧均在目标位置附近；这些场景只用于回归，不能代表所有真实画面。

首次完整布局布线生成了位流，但 HDMI 像素时钟域到串行时钟域的复位恢复路径有 4 个建立时序违例，最差余量为 -0.424 ns。更换布局种子重新实现后，最终建立时序余量为 +0.104 ns，保持时序余量为 +0.020 ns，违例均为 0；资源使用为 18981 slices、92 RAM、27 DSP。桌面交付文件的 SHA-256 为 `59390A87DDE3F4E0B67C0435118DE7F451C9E154E1304B0CB919BFA1D7E97A39`。

仿真场景不能代表所有真实画面，实际运动、遮挡、光照和纹理变化仍需上板验证。已知的快速反向合成场景可能出现一帧 HOLD。
