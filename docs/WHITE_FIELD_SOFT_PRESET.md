# 免操作的轻度空间补偿

本文件为经验补偿 V1 的历史记录。用户在原工程生成的 15:35 位流已包含 V1，但实拍仍偏绿；现已更新为 [白纸残差补偿 V2](WHITE_FIELD_PAPER_V2.md)。下文的中心系数、输入来源和 15:29 位流均对应 V1。V1 表已另存为 `white_field_soft_preset_v1.mem/.json`，默认 `white_field_soft_preset.mem/.json` 和内置常量现已是 V2。

用户反馈长按标定不方便，并提供了整体偏绿的画面。此前自标定版本固定了全局 AWB，未成功标定前无法补偿传感器原始色偏。本版恢复动态 AWB 和原自动曝光/按键行为，用最初白场图估计一组保守的位置相关色彩补偿，烧录后自动生效，无需白板、长按或等待状态条。

这是单张参考图估计的经验修正，不是实测镜头标定；无法保证完全去除所有光照/场景下的偏色。没有把后面那张固定 AWB 下明显偏绿的图作为系数来源，也没有用合成场景数据替代用户图像。

## 默认行为

`WHITE_FIELD_SELF_CAL=0`、`WHITE_FIELD_SOFT_PRESET=1`、`LSC_ENABLE=1`、`WHITE_FIELD_FIXED_AWB=0`。

KEY2 恢复按下切换 RAW/GRAY/COLOR/CANNY，KEY3 保持 AUTO/四档手动曝光。无标定状态条，无运行时采集，曝光变化或断电不会丢失内置补偿。固定系数通过 Verilog 常量初始化，没有对外部文件路径的运行时依赖，单独烧录 bit 即可。

## 系数依据

使用用户最初提供的 1920×1080 白场 PNG。去除四周 4 像素黑边后，在 16×9 节点附近做局部中位数和低分辨率平滑，仅拟合缓慢变化的颜色差异。按局部亮度估计 RGB 比例，再逐通道归一化平均增益，减少对原 AWB 的整体颜色调整的干扰。使用 85% 修正强度并限制增益在 0.90～1.10；最终 Q4.8 系数实际为 0.9336～1.0586。

中央节点 R/G/B 增益约为 `1.0586 / 0.9688 / 1.0156`：适度提高红色、压低绿色。该版本主要处理空间性色差，保留原图的亮度渐变，不把照明不均强行拉平。颜色增益仍可能改变部分高光的裁剪情况。

来源与可复现数据：

- 参考 PNG SHA256：`4AC51001942CD5145DF11D18874BD17874E943B9DC4100EFF82AEB3283271517`。
- `tools/estimate_soft_preset.py` 可重算系数；它不会修改输入图片。
- `hx1p35_port/white_field_soft_preset.mem` 和同名 JSON 保存系数与参数记录；同一组 144 个值内置在 `hx_pixel_stream_adapter.v` 的 `soft_preset_gain` 函数中。
- `tools/prepare_white_field_verification.py <新目录> --soft-preset --bitstream` 可构建该模式，同时生成独立像素参考向量。

实际主观改善需要烧录该模式后对比，不能由仿真图直接替代实拍结论。

对原参考图做数字估算（不是新实拍），中央区域 RGB 均值由约 `208.08/228.49/214.04` 变为 `217.37/223.01/217.34`，G−R 差值由约 20.41 降为 5.64。该结果只说明这组系数对提供的参考图具有减轻中央绿偏的方向，不能证明其它场景/光源下都适用。
