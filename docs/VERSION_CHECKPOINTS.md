# 版本检查点与回退记录

本文件记录经过综合分析、实现验证或实拍确认后值得长期保留的版本。普通修改仍按功能提交到 `WZY`；只有相对上一版出现明显提升时，才建立带说明的 Git 标签作为回退点。

## 评估和保存规则

每个候选版本至少检查：

1. 实拍效果：与上一版使用相同场景、距离、模式和曝光设置对比，记录轮廓完整度、噪点、颜色误检和明暗区域表现。
2. 工程实现：完成综合、布局布线和位流生成；记录 setup/hold WNS、违规端点和主要资源占用。
3. 功能回归：检查 RAW、GRAY、COLOR、CANNY 模式切换，自动/手动曝光、蜂鸣器和按键功能。
4. 可复现性：保存提交号、位流 SHA256、烧录文件位置和测试结论。

若效果只是参数尝试或尚未完成实拍，不标记为稳定里程碑，只记录为“候选版”。实拍确认明显优于上一版后，将其升级为“推荐回退点”并创建带注释的 Git 标签。

## 回退方法

优先从 Git 标签新建临时分支验证，不直接覆盖当前 `WZY`：

```text
git switch -c verify-<版本名> <标签名>
```

确认确实需要恢复后，再把该版本按正常提交方式合入 `WZY`，保留之后版本的历史记录。
