## 范围与方法

对 `D:\desktop\动捕参考代码\动捕参考代码` 的九个项目作了完整清单、逐文件读取和哈希去重；对压缩包展开读取各文件内容，重点阅读项目说明、工程启用情况、跟踪和图像处理核心代码。目录总计 5220 个普通文件，压缩包内还有 792 个非目录条目；其中大量为厂商 IP、工具数据库、仿真副本、图片和硬件原理图。二进制文件和厂商加密 HDL 只能检查类型和用途，不能通过文本阅读验证内部实现。报告中的判断针对相关自有源码，不表示逐行人工审计每个生成文件。

## 九个案例

1. **anlogic-ph1p35-vision**：同为 PH1P35、MIPI 到 HDMI，但以 SC500CS、像素算法、直方图均衡、自动白平衡等为主。可参考像素延迟和帧边界对齐，没有可直接用于任意目标的模板跟踪器；摄像头配置与已验证 SC520 基线不同。
2. **camera-filters**：Gamma、RGB/YUV、亮度对比度，Spartan FPGA，MIT。可参考显示调节，不是降噪或运动跟踪。源码中 `yuv2rgb.v` 的模块名也写为 `rgb2yuv`，其 YUV 实现对负色差信号做截断；不得直接当作经过验证的完整色彩转换模块使用。
3. **Color_Detection_BASYS3**：读取 COE 静态图片，检测和计数颜色圆形，擦除后继续扫描；适合固定背景的静态图形，并非实时任意物体跟随。
4. **FPGA_AL-main**：当前仓库的较早迁移版本，有单帧颜色统计和边缘显示，但不含目前已验证版本的模板跟踪与自动找回。可作为历史对照。
5. **FPGA-ANLU-National-First-Prize**：HX4S20C/EG4S20 的 UDP、SDRAM、OV5640 和视频处理，包含腐蚀/膨胀/Sobel 等，主要解决采集、传输及图像处理。主代码没有完整单目标跟踪器；工程工具兼容不等于 IP 和板级引脚可直接替换。
6. **fpga-defect-sorting-system**：Pango 100pro、OV5640，`source.zip` 中有形态学、前景框和缺陷定位等 Verilog，根目录 MIT。虽 README 称双级连通域，所检查的 `source/blob_analysis.v` 和 `source/blob_detector_improved.v` 实际是统计前景总面积和单个整体包围框，无法区分多个不相连物体；可参考阈值、面积、框更新与流水线结构，不是通用身份跟随方案。底层 Pango IP 不适用于本板。
7. **fpga-realtime-vision**：Intel/Quartus 示例中有 `rtl/vision/tracking/color_blob_tracker.v`、`kalman_1d.v` 和 `motion_detector.v`。前者为颜色阈值、预测位置窗口、质心、距离门控，后者用定点固定增益 α–β 更新位置和速度。README/CLAUDE 中描述了仿真，但本目录中所列 `tb_kalman_1d.v` 和 `tb_color_blob_tracker_v3.v` 未找到，当前顶层和 QSF 的跟踪模块也被注释，仓库声明 Kalman 修改未重新上板；不能视为可直接用的稳定整机。未发现根级许可证，复制代码前需确认授权。
8. **kv260-fpga-rgb-blob-overlay**：FPGA RTL 计算左右和上下像素 RGB 差，ARM PS 的 `color_boxes.hpp` 在 4×4 网格做区域生长，后续画框。不能把整个连通区域算法当成已经 FPGA 化；RTL 的像素差/握手和 PS 的种子颜色约束可作为独立参考。其工程 AXIS 的 TLAST 表示帧末，本工程视频链使用的行末语义须重新适配；未发现根级许可证。
9. **MIPI-CSI-2-HDMI-Bridge**：GateMate 与树莓派摄像头的 MIPI-DVI 通路及 PCB 原理图，不含目标跟踪，对当前算法帮助有限。

## 可移植方向与注意事项

- 优先参考 `kalman_1d.v` 的每帧位置/速度固定点 α–β 更新方法，设计为模板 SAD 成功结果的可选预测器；匹配结果和低置信度时回退基线，禁止把预测结果当成新观测。保留原始模板、VERIFY/HOLD/LOST 与自动找回。
- 原例程是颜色质心跟踪，多个同色区域在窗口内会共同参与质心；不是可区分任意物体身份的跟踪器，不能整套替代模板方案。它的 18 位像素数在 1280×720（921600 像素）下可能溢出，坐标预测未做图像边界饱和，漏检持续外推会漂移；参数、位宽和异常状态均需重新设计。
- `motion_detector.v` 的 `flush_col` 固定 5 位、行列地址和变化计数固定 9 位，480×272 的 30×17 配置不能直接升级到 1280×720 的 80×45 网格；还需处理帧首、缓存同步、亮度变化与相机移动造成的伪运动。
- ROI 颜色或局部对比度可作为可选提示，用来拒绝某些候选。它不足以保证同色目标之间的身份区分，不能作为唯一重找回条件。
- 几何框、面积及腐蚀膨胀适合作为颜色目标支路的独立试验；不宜直接作用于灰度模板输入，因为可能丢失模板纹理或合并多个物体。
- 拆分 OSD 展示坐标和平滑、跟踪搜索状态，用快速移动、急停、逆向、遮挡与跳变测试调参，避免仅让框变稳而把实际跟随变慢。
