# 双模板跟踪优化

实际工程入口仍为 `reference_edge_project/td_project/camera_to_dsi_display.al`。显示流水线启用 `ADAPTIVE_TEMPLATE=1`，保留十帧失配门限、半径 12 的局部搜索、80×80 显示框及仅 TRACK 显示方框的规则。COLOR 不进入模式切换。

初始模板由用户选取目标时建立，此后不自动改写，作为长期参考。短期模板与初始模板同时初始化，在 TRACK 中用于匹配；短暂 HOLD 期间冻结并继续用于局部恢复，进入 LOST/VERIFY 后改用初始模板重新确认。

短期模板只有在连续三帧通过更新条件时才更新：平均匹配误差不超过 8，最佳与其他独立候选的分数差至少 128，同时满足原有跟踪接受门限。更新前重新读取最佳位置的完整 64 个采样点，并检查它与初始模板去均值后的平均误差不超过 24、纹理幅度至少 24。这里的误差单位均为 8 位灰度值。

更新保留三位小数，每次融合四分之一新采样与四分之三旧模板，避免微小变化被整数舍入丢弃。新数据先写临时缓冲，全部校验通过后才提交；重置、重新选取或处理超时会使尚未完成的更新失效。匹配位置始终来自测量结果，模板更新不会直接移动显示框。

本次不加入旋转/尺度搜索，也不放宽正常跟踪的误差和唯一性门限。双模板帮助适应有限的渐变，不能保证大幅旋转、尺度变化、严重遮挡或相似背景下始终锁定原目标。

测试入口：`tools/test_gray_contours_tracking.ps1`。新增 `tests/tb_adaptive_tracking.sv` 对比渐变场景中的固定模板与双模板，并检查初始模板不变、遮挡期间不更新、短期恢复、初始模板重捕获及提交期间取消。先前固定模板回归仍通过默认关闭自适应的实例保留对照。
