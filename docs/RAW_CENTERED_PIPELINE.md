# 中心对齐 RAW 锐化修复（2026-10-20）

## 本轮修改

修复之前右下角像素减中心模糊值的方向性偏差：以窗口中心亮度减同中心 3×3 Gaussian 模糊值，得到的有符号增量作用于同一个中心 RGB，不能把增量施加到当前右下角像素。

只修改 hx_vision_pipeline.v 的显示路径及相关测试/说明。保持已有未提交修改；不改分辨率、帧率、引脚、SC520 配置、AE/档位/增益上限、Canny 运算、颜色统计/跟踪、DDR 或 I2C/CDC 握手。原 best_result 与历史位流不覆盖，不提交/推送。

## 流水线与对齐

为了等到中心像素右侧和下一行数据到达，增加显示侧 2048 时钟槽等待缓冲。每个槽存 RGB、模式、锐化开关、坐标及五个控制信号，包括所有消隐周期；不把图像内容向下/右挪一行，不裁掉四边，也不改变扫描周期。所有模式和 RAW 开关状态共用固定延迟。

输入 RGB 先走原来的显示预处理两级；新模块捕获完整 3×3 窗口，再依次寄存行加权和、模糊和、中心差分、绝对值/符号、门限/限幅。增量按中心像素的时钟槽写回独立修正 RAM，原像素离开等待缓冲时才读取修正，并做 RGB 饱和加法；之后的两级用于 RGB/坐标及 Logo ROM 对齐，最后叠加 OSD/Logo 输出。

等待缓冲与增量 RAM 使用双口 ERAM。增量 RAM 的读口先读后清零，复位后用完整 2048 时钟预热清理所有槽，不依赖 RAM 上电初值。头尾四边及 RAW/非 RAW 交界处没有完整同模式邻域时旁路，保留原像素。测光/跟踪不等待显示缓冲，也不接收锐化结果。

编译 ENABLE_RAW_SHARPEN=1 时，hx_vision_pipeline 输入到输出共 2054 拍，比原三拍增加 2051 拍（约 75 MHz 下增加 27.35 微秒）。编译关闭则保留原三拍路径。当前实际扫描每行 1650 拍，等待缓冲足以覆盖一行加一像素及运算时间；该界限是设计前提，不声称适配任意超长消隐或任意分辨率。

## 使用及 OSD

- 上电 RAW 原图，运行锐化默认关闭。
- KEY2 短按松开切模式；长按约一秒切 RAW 锐化，持续按住只触发一次，松开不切模式。
- RAW 开启显示 SHARP；其他模式不锐化，开关状态保留。KEY3 原功能不变。
- 门限 6、最大亮度增量 ±8、超过门限后半增益。只能改善观感，不能恢复失焦、削顶或远距离像素不足造成的信息丢失。
- AP E 为最后完整成功曝光写表值，不是毫秒；A 为 0x3e09，D 为 0x3e06/0x3e07 原始十六进制字节，不是倍数。WAIT/WR/OK/ERR 的 ACK 确认边界及错误保留语义保持不变，详见 RAW_DISPLAY_FEATURES.md。OK 不代表 FPGA 时序合格。
