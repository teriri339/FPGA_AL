# 恢复 RAW 显示直通（2026-10-19）

用户反馈近期 RAW 不如早期清楚，确认先撤回新增显示均值降噪及暗部曲线，单独检查原图细节，不同时修改曝光或 Canny 参数。

## 变化范围

`hx_vision_pipeline.v` 默认参数改为：

```verilog
parameter ENABLE_DISPLAY_DENOISE = 1'b0,
parameter ENABLE_SHADOW_LIFT = 1'b0,
```

- RAW：显示叠加前逐像素传递输入 RGB，不再做 2×2 平均或暗部映射。
- GRAY：显示 BT.601 定点灰度结果，不再额外平均或提亮。
- 两个增强模块的可选源码保留，可通过参数显式启用；生产默认关闭，工具可裁剪不用的逻辑与显示行缓存。
- Canny 六门限仍为弱 48/64/68、强 80/104/120，Gaussian/NMS/弱边处理/去孤点/连接均不变。本次不是 Canny 内部细节修复。
- 自动曝光与增益、手动档位、白平衡、白场 V2、MIPI/DDR/HDMI、原版 Logo/OSD、颜色统计和 10 帧保持均不变。

“恢复直通”只针对视觉显示模块，不是关闭整个 ISP，也不是恢复最早整个工程版本。RAW 仍经过前级 demosaic、AWB、DDR 和白场补偿；Logo/文字区域仍正常覆盖。显示延迟保留原三拍，未改分辨率。

关闭暗部曲线后部分区域可能比上一版稍暗，这是显示映射撤回，不是降低了曝光。关闭均值处理也可能使原始颗粒更明显；应先在同一机位、照明和稳定曝光下看细节差异，不承诺解决离焦、运动模糊、传感器高增益或原始采集质量问题。
