## 状态与使用

1. KEY3长按约1秒仍选定中央目标；首次TRACK、R:8仅为学习合格，R:1才是跨帧匹配成功。
2. 短暂失败仍HOLD，保留最后可靠位置；连续16次失败进入LOST。
3. **LOST不再清除模板或停止搜索**。逐帧交替搜索最后可靠位置和画面中央附近，使用原冻结模板，不自动重学当前背景。
4. 找到合格候选先显示黄色VERIFY、R:9。跟踪框展示待确认候选，但内部最后可靠位置保持原值。
5. 必须连续3个完整搜索结果都通过误差/唯一性检查，且相邻候选每轴移动不超过12像素，才恢复绿色TRACK；恢复当次R:A（十六进制10），随后正常R:1。
6. 任一次匹配失败、采样不完整或处理超时都会清零确认次数、回到LOST继续交替搜索。单帧闪现不能恢复TRACK。
7. LOST时长按KEY3可以放弃旧模板并手动重新选定；TRACK/HOLD/VERIFY时长按解除，解除后READY不自动找回。KEY3短按曝光与KEY2原功能均不变。

在匹配稳定的理想情况下，约3～4个完整搜索帧（其中至少3帧连续通过）即可找回；实际时间取决于帧率、目标位置、画面变化和匹配情况，不保证固定毫秒数。每个窗口仍只有约±9像素范围，边界夹紧；并非在两个位置之间的所有区域或全画面搜索。

模板固定且尺度/方向固定；若目标回来时大小、角度、动画姿势或曝光造成的外观变化过大，仍可能匹配失败。完全相同外观的替代物不能靠本算法可靠区分，不宣称物体身份识别。连续确认用于减少瞬时误锁，不是身份认证。
