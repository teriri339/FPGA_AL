- 搜索块改为80×80连续亮度像素，6400字节片内存储。先做9×9、2像素步进的零均值SAD搜索，再对两个相隔超过6像素的候选峰分别做3×3、1像素步进细化；两个细化峰和远处粗搜峰一起参与歧义拒绝。

- 连续16次失败仍LOST并停止搜索，保留最后可靠位置；HOLD期间可恢复，LOST须重新选定。未加入自动重学背景。

## 操作和调试

KEY3长按约1秒：READY/LOST/FLAT时选定中央，LEARN/TRACK/HOLD时解除；短按保持原曝光功能。KEY2短按模式、长按RAW锐化不变。原C/X/Y/P和顶行TRACK/HOLD/LOST仍是颜色跟踪；模板请看第三行TPL和跟踪框。

第三行 `TPL: ... E:xxxx U:xxxx R:x M:xx` 的数字均为十六进制：

| 字段 | 含义 |
| --- | --- |
| E | 最近一次完整搜索的最佳64点总误差，≤0300才可能通过 |
| U | 不同候选峰的误差差距，≥0040才可能通过；不是相邻像素间差值 |
| R:0 / R:1 | 等待 / 跨帧匹配通过 |
| R:2 / R:3 | 匹配误差过大 / 多个峰不够唯一 |
| R:4 / R:5 | 搜索块或模板不完整 / 计算超时跨入下一帧 |
| R:6 / R:7 / R:8 | 纹理不足 / 主动解除 / 模板已学好但尚未跨帧匹配 |
| M | 内部连续失败计数器；第16次进入LOST不再递增，保留0F |

E=7FFF、U=0是等待/重选的初值，不是有效匹配结果。R:4/5时E/U保留上次完整搜索值，应优先读取R。学习合格显示TRACK时R:8，不能误认为已经连续跟踪成功。稳定跟踪应为R:1。
