# 低资源分片全画面找回

## 新增能力与边界

在扩大找回A基础上，LOST后除最后可靠位置/中央及邻域，还逐窗口扫描整个1280×720画面。仅寻找用户此前选定的冻结模板，不是物体类别识别，不支持旋转/尺度变化、严重变形或失焦恢复。

前32次失败搜索仍完全沿用原近邻/远邻调度；此后一个局部窗口、一个全画面窗口交替。局部窗口保留原3近邻+1远邻的顺序，只有处理局部窗口才推进局部游标。全局窗口从左上向右下按16处理像素步长扫描，中心范围x=32..1248、y=32..688，共77×42=3234个窗口。边缘窗口使用已有80×80 ROI钳位；其他尺寸最后一行/列钳位到合法最大中心，不假定尺寸能整除16。

每个窗口仍使用原64点零均值SAD、两轮细化、原误差/唯一性门限、3帧连续确认；每帧只捕获/计算一个80×80块，ERAM搜索缓存深度不变，不加整帧RAM、不访问或修改DDR。新增GLOBAL_REACQUIRE参数默认开启，关闭时应与上一扩大找回A逐周期相同。

**速度限制：不是秒级全画面检测。** 一轮全局扫描3234个窗口，在局部/全局交替下需要6468个持续失败搜索帧；连同最初32帧局部优先，60fps且每帧正常参与搜索时理想约108.3秒，再加确认。目标重新出现时取决于当前扫描位置，可能较快，也可能接近两分钟；缺帧、VERIFY失败、目标持续移动等可能更久，不保证恢复时间。局部持续重访，但暖机后频率是旧版一半，远邻完整轮询也从576延长为1152个搜索帧。

全画面扫描只覆盖完整64×64模板能容纳的合法中心范围；目标被画面边缘裁掉时不保证匹配。唯一性只在当前搜索块内检查，不是全画面的唯一身份验证；相似物体、重复图案仍可能误锁。接受候选后进入黄色VERIFY，不立即移动可靠中心或更新模板；连续3帧确认后绿色TRACK/R:A。全局提案时就推进全局游标，防止短暂闪现的候选反复阻塞同一窗口；VERIFY过程中只搜待确认位置，失败后恢复局部/全局调度。

扫描期间第三行TPL仍显示LOST，没有新增SCAN字样或进度条；LOST不代表停止搜索。顶行TRACK/LOST及C/X/Y/P仍属于颜色跟踪，不能用顶行判断模板是否自动找回。
