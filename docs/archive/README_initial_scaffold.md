# FPGA Real-Time Image Processing（初始脚手架存档）

> 来源：提交 `c401862`。以下内容为仓库创建时的规划，部分目录和命令并未在当前工程中实现。

基于 **安路 FPGA** 的实时数字图像处理系统。采集 → 处理 → 显示全流水线的硬件实现。

## 初始规划结构

```text
.
├── board/                  # 板级资料：原理图、引脚表
├── doc/                    # 设计文档
├── hw/
│   ├── constr/             # 约束：引脚 .adc / 时序 .sdc
│   ├── ip/                 # 工具生成的 IP 核
│   ├── sim/                # 仿真文件和波形
│   └── src/                # 顶层、采集、处理、显示与通用模块
├── scripts/                # 综合 / 实现 / 下载脚本
├── sw/                     # 上位机及 MCU 软件
└── tools/                  # 第三方工具依赖说明
```

## 初始数据通路

```text
摄像头 → 采集 → 行缓存 → 算法流水线 → 显示时序 → 显示屏
```

## 初始开发约定

- 一个模块一个文件，文件名与模块用途对应。
- 跨时钟域信号必须显式同步。
- 每个流水线级的延迟应在模块头部说明。
