# 白场校正验证记录（2026-10-17）

本文件是先前静态表实现的历史验证记录；当前默认配置已改为板上自标定，使用步骤与新版本结果见 [板上白场自标定](WHITE_FIELD_SELF_CALIBRATION.md)。下述资源和“默认旁路”描述对应当时的静态表版本。

结论：发现并修正首版坐标组合除法导致的时序违例；修正版在合成白场条件下通过 RTL 仿真和完整工程综合、布局布线、静态时序检查。未生成新位流或烧录，主工程仍默认旁路。真实标定和实拍效果仍待验证。

## 修正与测试

首版五级实现的坐标换算在像素路径上执行组合除法。首轮完整布线结果 Setup WNS `-2.439 ns`，76 个 setup 违规端点，不能作为可上板版本。修正为编译期生成横纵坐标 ROM、运行时同步查表；流水线从五级增为六级，像素与 VS/HS/DE/USER/LAST 一起延时。增益表格式和数值算法不变。

## 完整工程物理实现

工具 Tang Dynasty `6.2.168116`，器件 `PH1P35MDG324`，速度档 3。使用当前 `.al` 的源码清单与排除项、现有引脚和时序约束，在独立目录复制源码后修改验证副本的参数；没有修改用户已有的 `.al` 改动，也没有覆盖原构建结果。

| 资源 | 布线后使用量 |
| --- | ---: |
| Slice | 8720 / 21216（41.10%） |
| LUT6 | 7518 / 21216（35.44%） |
| 寄存器 | 8811 / 42432（20.76%） |
| ERAM | 54 / 108（50.00%） |
| DSP | 15 / 40（37.50%） |

综合 Setup WNS `+0.860 ns`；最终布线 Setup WNS `+0.223 ns`、Hold WNS `+0.020 ns`，setup/hold TNS 均为 0，违规端点均为 0。实际像素时钟约 75.002 MHz。

这些是“固定 AWB + 该合成表”的整机占用，不能直接拿来推算 LSC 的增量：固定 AWB 会消除原动态增益计算逻辑，实际增益表数据也会影响综合优化。重新启用动态 AWB 或更换表后必须重跑工具。

静态时序报告覆盖率为 93.30%，不是所有电路/外部接口都被穷尽验证。日志仍有原基线已有的 I2C 时钟混合负载、PLL 输出 IO 等告警；另有 ROM 数组初始提取时的无运行时驱动提示，后续综合确认推断 ROM 并保留初始化。没有执行全芯片门级功能仿真。上述结果不替代板上启动、摄像头采集、显示、曝光控制以及真实标定有效性的检查。
