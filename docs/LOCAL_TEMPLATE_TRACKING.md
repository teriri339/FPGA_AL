# 中央选定与小范围模板跟踪原型

## 目标、范围与操作

本次只新增中央选定目标、局部模板匹配、显示框和 TPL 状态，不新增串口、数值坐标显示或外部控制；不是任意物体语义识别或全局运动检测。原颜色跟踪、C/X/Y/P、色块告警及 Canny 保留；已有 C/X/Y/P 和顶部旧 TRACK/HOLD/LOST 仍属于颜色检测，不能当成本功能结果。请看新增的第三行 TPL 状态和对应框。

- 上电在 RAW/GRAY 显示中央 64×64 青色选择框，TPL: READY。
- 把有明显纹理的目标区域放进中央框并稳住相机，单独长按 KEY3 约一秒。自动回 RAW，下一完整帧采集模板，显示 LEARN 黄色框。
- 模板纹理足够后进入 TRACK 绿色框，缓慢移动相机，框在附近搜索跟随。不是识别物体类别，而是匹配选定图案。
- 不可靠匹配进入 HOLD 橙框，保留最后可靠位置；连续16个失败搜索帧后 LOST 红框，停止自动搜索，需重新选定。
- FLAT 紫框表示选区缺少纹理或采集无效，移到有文字/图案/角点的区域后重新长按 KEY3。
- TRACK/HOLD/LEARN 时长按 KEY3 解除回 READY；再次长按选定新目标。LOST/FLAT 时长按可直接重新选定中央目标。
- KEY3 短按松开仍依次切 AUTO/EXP0/EXP1/EXP2/EXP3；为区分长按，短按动作从按下改到松开执行。长按不切换曝光模式/档位；AUTO时原AE仍继续工作。KEY2 短按切模式、长按 RAW 锐化不变。不要同时按两键。
- 框仅叠加到 RAW/GRAY，COLOR/Canny 保持原图像算法；TPL 状态行仍可见。

## 算法与限制

初始模板为64×64区域中的8×8采样网格，采样间距8像素；取现有3×3 Gaussian 灰度寄存结果，避免锐化进入跟踪。采样相位选为每格内x/y偏移2像素，避开每帧最上/最左两行列的不完整窗口，不读取上一帧残留作为目标特征。只保留64字节初始模板及16×16搜索采样块，不访问DDR或新增整帧缓存。

每帧在上次可靠中心附近±32像素搜索9×9个候选，采用零均值绝对差和（ZM-SAD）：先求候选均值，再比较 `(候选样点-候选均值)-(模板样点-模板均值)` 的绝对值。均值补偿只针对加性亮度变化，不等价于完整曝光/增益/白平衡不变性。模板冻结，不自动更新，以减少背景漂移。

有效锁定必须同时满足：模板灰度范围至少24、64点总绝对偏差至少384；最佳匹配总误差不超过768（平均12）；次佳误差至少比最佳大64。均匀表面、重复图案、多义候选不会强行锁定。候选按固定顺序串行运算，读地址/同步读/累加分阶段，在垂直消隐计算约31,200拍；当前扫描垂直消隐约49,500拍。若下一帧已开始但计算未完成，丢弃该次结果并进入保持/丢失，不发布过期匹配。

边界处搜索窗口夹紧到图像内部，64×64框不越界。输出位置网格分辨率8像素，可能出现8像素阶梯，不是亚像素跟踪。模板尺度固定；不承诺大幅晃动、旋转、变焦、遮挡重识别或离开搜索区后的自动找回。实际相机运动下的稳定性待实拍，合成测试通过不代表任意物体可用。

READY/解除/重新选定均回中央。内存无需上电初值：完整模板与搜索块计数合格后才启用匹配。学习失败、搜索块不完整、重复纹理或超时不更新可靠位置。

源码第三行新增 `TPL: ... E:xxxx U:xxxx R:x M:xx`，数值均为十六进制：E为最近一次完整搜索最佳64点总误差，U为次佳减最佳，R为最近判定原因，M为内部连续失败计数器（进入LOST的第16次不再递增，因此保留0F）。R=0等待，1匹配通过，2误差过大，3候选不唯一，4采样不完整，5计算跨入下一帧，6纹理不足，7主动解除，8模板学习合格但尚未完成匹配。等待或重新学习时E=7FFF、U=0，不能当作有效匹配分数。采样或超时失败时E/U仍为上次完整搜索结果，应优先读R。LOST保留末次诊断供拍照。
