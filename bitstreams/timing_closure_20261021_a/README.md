## 本次变化与保留功能

- 修正测光快照消费时序，SC520 I2C 改为主时钟加时钟使能；不改变曝光算法、档位和增益上限。
- 各时钟域复位同步释放，串行器独立释放；CDC 使用有限数据路径延迟预算，FIFO 灰码约束不再被整域屏蔽。
- DDR 输入参考接现有 100 MHz PLL 输出，匹配 IP 标称配置；tCK 对齐 1875 ps，写恢复参数为 8 周期。相对原来错误接入的 50 MHz，实际 DDR 时钟发生修正，必须上板验证稳定性。
